## 1. 为什么选择 VTX316

| 指标 | 宇音天下 VTX316 | 友商某品 |
|------|-----------------|----------|
| 芯片方案 | 单芯片，尺寸小，管脚少，外围简单成本低（QFN32，4×4mm） | 双芯片，尺寸大，管脚多，外围复杂成本高 |
| 模块方案 | 模块尺寸小且薄（21.6×17mm） | 尺寸大 |
| 功耗性能 | 超低功耗（见下表） | 功耗很高，不支持睡眠 |
| 出音响应时间（发命令到出音，例：“你好”） | 出音响应快，小于 200ms | 慢，大于 1200ms（延时感很强） |
| 上电启动时间（上电到初始化完毕） | 上电启动快，小于 200ms | 慢，大于 1200ms |
| 中文语音合成效果 | 发音清晰，无杂音 | 辨识度较低，有杂音 |
| 含英文字母文本播放（例：沪 NZ5E18 / https://www.baibu.com） | 英文字母合成播音清晰 | 辨识度低，部分听不清 |
| 可打断上次播新 TTS | 可实时打断播新 TTS 文本 | 不支持（需等上次 TTS 文本播完） |
| 播完主动通知空闲 | 播完主动通知空闲状态 | 不支持 |
| 提示音连播 | 可一次连播多个提示音 | 不支持 |
| 文本智能分析 | 日期、号码、符号等智能分析强 | 智能分析弱 |
| 文本控制标记 | 10 多种控制标记，灵活性高 | 只有几种 |
| 波特率及编码 | 4 种波特率，4 种文本编码 | 2 种波特率，2 种文本编码 |

**功耗分项（VTX316）**

| 状态 | 芯片 | 模块 |
|------|------|------|
| 睡眠 | 2uA | 3uA |
| 待机 | 7mA | 9mA |
| 播音 | 10mA | 23mA |

> 注：以上为 2025 年 7 月 31 日测试的结果。

## 2. 芯片功能简介

### 体积精巧

- 封装方式：QFN32  
- 体积大小：4×4mm  

![](images/8d8b89732ba75882c1a866b01f6fed0ec35c13cb9a7e6445d7bb2835a8705d46.jpg)

### 超强性能

- 单次支持 4000 字节文本合成  
- 支持 UTF8、GBK、GB2312、UNICODE 编码  
- 8 种发音风格  
- 10 多种灵活控制标记  
- 支持参数掉电保存  
- 0.1 秒快速合成播音  

### 开发简单

支持 UART 串口，4 种波特率配置，提供快速测评方法和成熟的文档体系，以及专业的技术支撑。

## 3. VTX316 语音合成模块介绍

![](images/f55ec740f4bed6a4784439238dd982510ca15a6043e0385c490d88f0ddc239bb.jpg)

模块比 1 圆硬币还要小。丝印可见 `YYTX-V2.2A`。

### 引脚定义

![](images/e8dd9d83c8202b07d945ff9c4d705dc2939073e8081f8e880a881535311eba34.jpg)

| 引脚编号 | 引脚定义 | 说明 |
|----------|----------|------|
| 01 | BAUD0 | 波特率配置端口 0 |
| 02 | BAUD1 | 波特率配置端口 1 |
| 03 | AO | 音频输出 |
| 04 | R/B | 芯片忙状态指示，低电平表示空闲 |
| 05 | RESET | 复位脚（保持 1 秒以上低电平复位） |
| 06 | SP+ | 接喇叭正 |
| 07 | SP- | 接喇叭负 |
| 08 | GND | GND |
| 09 | VCC | 5V 供电 |
| 10 | RXD | 模块串口接收 |
| 11 | TXD | 模块串口发送 |

### 模块参数（原图示意）

![](images/5d606cbca8007a28396a662f94f2cb670a29548631d8857e960b6bdda50869bd.jpg)

上位机常用按钮示意：合成 / 停止 / 暂停 / 恢复 / 唤醒 / 深睡 / 查询状态 / 版本号 / 唤醒+合成+深睡 / 清空文本 / 清空日志。

## 5. 语音合成命令

| 帧头 | 数据长度 | 命令字 | 编码格式 | 文本数据 |
|------|----------|--------|----------|----------|
| `0xFD` | `0xXX 0xXX` | `0x01` | 见下表 | `0xXX 0xXX …` |

**编码格式参数**

| 值 | 含义 |
|----|------|
| `0x00` | GB2312 编码 |
| `0x01` | GBK 编码 |
| `0x03` | UNICODE 小头 |
| `0x04` | UNICODE 大头 |
| `0x05` | UTF8 编码 |

**举例**：合成 GBK 文本「宇音天下」

```text
0xFD 0x00 0x0A 0x01 0x01 0xD3 0xEE 0xD2 0xF4 0xCC 0xEC 0xCF 0xC2
```

## 6. 其它控制命令

| 命令名称 | 命令举例 | 回传解释 |
|----------|----------|----------|
| 睡眠 | `0xFD 0x00 0x01 0x22` | 无 |
| 睡眠 | `0xFD 0x00 0x01 0x88` | `0x4B`：芯片进入深度睡眠模式 |
| 唤醒 | `0xFD 0x00 0x01 0xFF` | `0x4A`：唤醒成功 |
| 停止播音 | `0xFD 0x00 0x01 0x02` | `0x41`：接收成功 |
| 暂停播音 | `0xFD 0x00 0x01 0x03` | `0x41`：接收成功 |
| 恢复播音 | `0xFD 0x00 0x01 0x04` | `0x41`：接收成功 |
| 忙闲状态 | `0xFD 0x00 0x01 0x21` | `0x4E`：播音中；`0x4F`：空闲中 |
| 查询版本号 | `0xFD 0x00 0x01 0x58` | `0x58`：回传版本号 |

### 回传说明

| 回传类型名称 | 回传命令 | 备注 |
|--------------|----------|------|
| 初始化成功回传 | `0x4A` | 回传包含 `0x4A` 则代表「初始化成功」 |
| 命令接收成功回传 | `0x41` | 收到正确的命令帧时回传 |
| 命令接收失败回传 | `0x45` | 收到错误的命令帧时回传 |
| 空闲回传 | `0x4F` | 播音完毕或参数配置成功时回传 |

## 7. 文本控制标记说明

| 标记名称 | 控制标识 | 默认 | 参数说明 |
|----------|----------|------|----------|
| 发音人选择 | `[m*]` | `[m3]` | `*=3` 晓玲（女声）；`*=51` 尹小坚（男声）；`*=52` 易小强（男声）；`*=53` 田蓓蓓（女声）；`*=54` 唐老鸭（效果器）；`*=55` 小燕子（女童声）；`*=56` 贝童（男童声）；`*=57` 晓可（男童声） |
| 数字处理策略 | `[n*]` | `[n0]` | `*=0` 自动判断；`*=1` 数字作号码处理；`*=2` 数字作数值处理 |
| 语速调节 | `[s*]` | `[s5]` | `*=0~30` 语速值 |
| 语调调节 | `[t*]` | `[t5]` | `*=0~10` 语调值 |
| 音量调节 | `[v*]` | `[v5]` | `*=0~10` 音量值 |
| 提示音策略 | `[x*]` | `[x1]` | `*=0` 不使用提示音；`*=1` 自动使用提示音 |
| 中文拼音识别 | `[i*]` | `[i0]` | `*=0` 不识别汉语拼音；`*=1` 识别汉语拼音 |
| 姓名读音策略 | `[r*]` | `[r0]` | `*=0` 自动判断；`*=1` 每句开头字按姓氏读音；`*=2` 紧跟句的开头按姓氏读音 |
| 号码「1」读法 | `[y*]` | `[y0]` | `*=0` 读成「幺」；`*=1` 读成「一」 |
| 韵律标注策略 | `[z*]` | `[z0]` | `*=0` 不处理韵律标注；`*=1` 处理韵律标注 |
| 发音风格 | `[f*]` | `[f1]` | `*=0` 一字一顿；`*=1` 平铺直叙 |
| 读标点策略 | `[b*]` | `[b0]` | `*=0` 不读标点符号；`*=1` 读标点符号 |
| 恢复默认 | `[d]` | - | 恢复默认（除发音人外） |
| 强制改变读音 | `[=*]` | - | 例：`他[=ni3]们` → 「他」读成「你」 |
| 静音时间 | `[p*]` | - | `*=0~32000`（ms）；例：`宇音[p1000]天下` → 播完「宇音」后静音 1000ms 再播「天下」 |
